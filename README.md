# Sistem Manajemen Inventaris Produk

Proyek 1 - Mata Kuliah Struktur Data
Program Studi Teknik Informatika

## Deskripsi
Program ini merupakan sistem manajemen inventaris
produk sederhana berbasis Command Line Interface.

## Struktur Data
Hash Table menggunakan Python Dictionary (dict).

## Operasi
1. Insertion (Tambah Produk)
2. Searching (Cari Produk)
3. Deletion (Hapus Produk)

## Menjalankan Program

python main.py

## Menjalankan Pengujian

python -m unittest discover -s tests -v
